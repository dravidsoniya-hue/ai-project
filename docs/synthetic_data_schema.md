# Fix2Runbook — Synthetic Data Schema Reference

> **RAALE Feedback Addressed**: This document provides explicit synthetic data schemas, field-level definitions, sample records, and module references for all generated ERP datasets.

---

## 1. Overview

The synthetic ERP dataset is generated by [`backend/app/data/synthetic_generator.py`](../backend/app/data/synthetic_generator.py) and seeds the SQLite database at startup.

**Dataset Scale:**
| Entity          | Count | Modules Covered             |
|:----------------|:-----:|:----------------------------|
| Business Rules  | 40+   | All 10 ERP modules          |
| Incidents       | 32    | Tax, Inventory, Payments, Pricing, Procurement, Order Mgmt, Payroll, Customer Mgmt, Access Control |
| Pull Requests   | 32    | One per incident            |
| Code Diffs      | 32    | One per PR                  |
| Reviews         | 32    | One per PR                  |
| Events          | 110+  | Includes duplicates, delayed, out-of-order cases |
| Experiment Tasks| 10    | 10 distinct benchmark tasks |

### 2.4 CodeDiff

**Table**: `code_diffs`  
**Source**: [`backend/app/models/models.py`](../backend/app/models/models.py)  
**Schema**: [`backend/app/schemas/schemas.py#CodeDiffBase`](../backend/app/schemas/schemas.py)

| Field                    | Type   | Description                                         | Example                          |
|:-------------------------|:-------|:----------------------------------------------------|:---------------------------------|
| `diff_id`                | String PK| Unique diff identifier                            | `"DIFF-142"`                     |
| `pr_id`                  | String FK| Associated PR ID                                  | `"PR-142"`                       |
| `commit_id`              | String | SHA commit hash                                     | `"abc1234def5678"`               |
| `files_changed`          | JSON   | List of file paths modified in this diff            | `["erp/pricing/tax_engine.py"]`  |
| `diff_text`              | Text   | Unified diff text (git-format)                      | `"- tax = sub * RATE\n+ disc = sub - promo\n+ tax = disc * RATE"` |
| `business_rules_affected`| JSON   | List of rule codes annotated in changed files       | `["RULE-TAX-104", "RULE-PRC-078"]` |

**Sample Unified Diff (INC-052 / PR-142):**
```diff
--- a/erp/pricing/tax_engine.py
+++ b/erp/pricing/tax_engine.py
@@ -42,8 +42,9 @@
 def calculate_invoice_total(subtotal, promo_discount, tax_rate):
-    # BUG: Tax applied before promotional discount deduction
-    tax_amount = subtotal * tax_rate
-    final_total = tax_amount - promo_discount
+    # FIX (RULE-TAX-104): Discount must precede tax calculation
+    discounted_subtotal = subtotal - promo_discount
+    tax_amount = discounted_subtotal * tax_rate
+    final_total = discounted_subtotal + tax_amount
     return final_total
```
